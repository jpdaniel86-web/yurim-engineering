## 창작·편집 요소

메인 문구, CEO 인사말, 사업별 서비스 설명은 홈페이지 편집 문안이다. 대표자 이름·발언·서명, 설립일, 면허번호, 인증서, 건설 실적을 임의로 만들지 않았다. 법인 연혁과 면허 원본, 장비 제원은 미제공이므로 상담 안내 형태로 구성했다.

현재 로고는 2026년 10월 15일 사용자가 선택한 명함의 YURIM 타원형 로고를 SVG로 재구성한 것이다. 같은 날 사용자가 명함 속 인물이 CEO임을 확인하고 사진 게재를 요청하여, 인물 부분만 잘라 CEO 인사말에 대표이사 이명규의 사진으로 사용했다. 얼굴을 생성하거나 외모를 수정하지 않았다. 명함 원본 이미지·개인 휴대전화·개인 이메일은 홈페이지와 저장소에 포함하지 않았다. 하수처리·관로·콘크리트·천공·IoT·바이오 SVG는 이해를 위한 개념 이미지이며 실제 시공 사진이 아니다. 음성·양주 사례에는 다른 현장 사진을 대신 사용하지 않았다.

현재 인트로는 블루 CI에 맞춰 2026년 10월 15일 Higgsfield MCP / Seedance 2.5로 생성한 1920×1080, 24fps, 약 8.04초 무음 영상이다. 푸른 물길과 환경 기반시설을 표현하며 실제 유림 시공 현장 촬영이 아니다. H.264 버전은 `public/assets/yurim-blue-intro-1080p.mp4`, 정지 포스터는 `public/assets/hero-blue-poster.jpg`다. 기존 10.04초 영상과 원본 다운로드 파일도 보존했다. 추가 유료 생성은 비용·개수를 안내하고 사용자의 명시적 동의를 받은 후에만 진행한다.
