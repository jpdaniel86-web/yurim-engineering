# 콘텐츠와 자료 근거

브랜드와 연락처는 사용자 지정 정보인 **유림엔지니어링(주)**, 전화 **031-774-8358**, 팩스 **031-774-8359**, 창대리 649-6 / 남북로 62 에이스빌딩 2층을 적용했다. 과거의 유림환경 법인명, 제주 사업 계획과 연락처를 현재 회사의 사실로 옮기지 않았다.

## 메뉴

엑셀의 환경 → 건설 → 시공실적 → 기술·장비 → 회사소개 → 자료실 → 문의 순서와 상세 메뉴를 적용했다. IoT 스마트 관리는 개인하수처리시설 관리 아래, 수평오거천공은 철근콘크리트공사 아래의 하위 항목으로 표시한다. 기술·장비 표의 `하수처리 기술` 중복은 사용자의 승인으로 한 번만 표시했다.

## 확인된 자료

- `유림엔지니어링_Bio_Gold-200.pdf`: 사업 분야, Bio Gold-200 소개, 19종 미생물 군집, 제품 개발 기록, 양평 20톤/일·음성 약 2,500두·양주 젖소농장 적용 사례. 원문은 자료실에서 제공한다.
- `슈퍼바이오골드-200_실증결과.pptx`: 양평 양동면 양돈농가 2,600두, 2026년 4월 30일~5월 30일, 4개 측정 지점·5회 측정. 실증 페이지 사진은 이 원문에서 추출했다.
- `유림환경 소개.pdf`: 과거 환경 사업 방향 참고. 별도 법인과 미래 계획이 섞여 있어 현재 회사의 확정 실적·규제·인증으로 재사용하지 않았다.

암모니아 수치는 요약문의 평균(17.9→1.4ppm)과 원표가 일치하지 않는다. 차트는 원표의 육성사1 17.6→1.2, 육성사2 18.2→1.7, 비육사 17.8→1.3, 돈분저장소 8.3→0.2ppm을 표시한다. 결과 페이지에 불일치와 출처를 설명했다. 93.3%를 전체 사업의 보장 성능으로 광고하지 않았다.

## 창작·편집 요소

메인 문구, CEO 인사말, 사업별 서비스 설명은 홈페이지 편집 문안이다. 대표자 이름·발언·서명, 설립일, 면허번호, 인증서, 건설 실적을 만들지 않았다. 법인 연혁과 면허 원본, 장비 제원은 미제공이므로 상담 안내 형태로 구성했다.
